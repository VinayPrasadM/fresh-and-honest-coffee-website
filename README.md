# Fresh & Honest: Coffee Brand Website

> **Case study.** This is client work, so the source code stays private to the client. This repo documents what I built and how.

![Fresh & Honest website](https://framerusercontent.com/images/azzZfmsbroNyzoCjCNCNZ0Qs.png)

**Live:** [freshandhonest.com](https://freshandhonest.com/) · **Client:** Fresh & Honest, India · **Role:** Front-end development at Fuego Media Services

## The brief

Fresh & Honest is an Indian coffee company brewing since 1996, serving hotels, offices and vending partners. They needed a brand website that explains each business line and brings in enquiries.

## What I built

A hand-coded brand website, built from scratch without a page builder.

- Sections for each business line: HoReCa (hotels, restaurants and cafés), office coffee solutions and vending
- Partner, product and contact pages
- PHP-powered pages and enquiry forms
- Sliders and scroll animations, fully responsive on mobile

## Tech

| Layer | Stack |
| --- | --- |
| Front-end | HTML5, CSS, Bootstrap, JavaScript, jQuery |
| UI | Swiper sliders, AOS scroll animations |
| Server | PHP pages and enquiry forms |
